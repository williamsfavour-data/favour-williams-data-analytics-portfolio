Project 3: AI-Assisted Sales Intelligence Dashboard

Tool: Microsoft Excel and AI-assisted reporting
Project Type: Data Analytics Portfolio Project
Dataset: Sales transaction data

Project Overview

This project demonstrates how Microsoft Excel and AI assistance can be used to analyse sales data, present key performance indicators, and communicate business insights through a dashboard.

The goal is to transform sales information into a clear visual report that helps users understand business performance and identify areas that may require further investigation.

Project Objectives

- Organise and analyse sales transaction data.
- Summarise important sales performance indicators.
- Compare sales performance across relevant business categories.
- Present findings using charts and dashboard visuals.
- Use AI assistance to support insight development and report writing.
- Communicate findings in a clear, professional format.

Tools and Skills

- Microsoft Excel
- Data organisation and analysis
- KPI reporting
- Dashboard design
- Data visualisation
- AI-assisted reporting
- Business insight communication

Business Value

A sales intelligence dashboard can help business users monitor performance, compare results, and identify trends that deserve further analysis. Presenting information visually also makes it easier to communicate findings to managers and other stakeholders.

How AI Was Used

AI assistance supported the organisation of the project, the development of explanatory insights, and the preparation of the report. The analyst remains responsible for checking the calculations, validating interpretations, and ensuring that recommendations are supported by the data.
