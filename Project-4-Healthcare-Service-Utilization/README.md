Project 4: Healthcare Service Utilization Analysis

Tool: Microsoft Excel
Project Type: Healthcare Data Analytics
Dataset: Healthcare service utilization data

Project Overview

This project analyses healthcare service utilization data using Microsoft Excel. The goal is to organise healthcare information, summarise important performance indicators, and present findings through an interactive dashboard.

The project explores healthcare service activity, patient visits, waiting times, treatment costs, patient satisfaction, and follow-up information.

Project Objectives

- Analyse healthcare service utilization patterns.
- Summarise key healthcare performance indicators.
- Examine patient visits across departments and age groups.
- Explore waiting times and treatment costs.
- Review patient satisfaction and follow-up completion.
- Present findings through charts, summaries, and a dashboard.

Tools and Skills

- Microsoft Excel
- Data organisation and cleaning
- Data analysis
- KPI reporting
- PivotTables and charts, where applicable
- Dashboard design
- Data visualisation
- Communicating data-driven insights

Key Areas of Analysis

- Service utilization: Understanding patterns in healthcare visits.
- Patient activity: Reviewing visit volumes and patient groups.
- Waiting time: Exploring how long patients wait for services.
- Treatment costs: Examining healthcare costs.
- Patient satisfaction: Reviewing satisfaction indicators.
- Follow-up completion: Exploring whether follow-up care is completed.
- Department performance: Comparing service activity across departments.

Business and Healthcare Value

Healthcare data analysis can help healthcare teams identify service patterns, monitor operational indicators, recognise areas that may need improvement, and support evidence-based planning.

The dashboard provides a visual summary that makes key information easier to understand and communicate.

Data and Privacy Note

If this workbook uses synthetic or sample data, the results should be treated as a demonstration rather than actual hospital performance. No real patient-identifying information should be published in a public portfolio.

Conclusion

This project demonstrates how Microsoft Excel can be used to organise healthcare data, analyse service utilization, and communicate findings through dashboard visualisation. It reflects my developing skills in data analytics and my interest in applying data to healthcare and public health.
